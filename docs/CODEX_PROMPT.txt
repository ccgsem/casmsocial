Use `docs/agent_communication_design.md` as the source of truth and implement the first working version of the communication architecture.

Goals:
- Preserve the existing `Person` and `Place` implementations where practical.
- Add a `CommunicationManager` that handles:
  - local delivery
  - remote one-way delivery
  - remote two-way delivery with acknowledgments
  - MPI rank-based buffering and exchange
- Rebuild place membership after movement each tick.
- Ensure person ownership follows the rank of the current place.
- Keep communication decision-making on `Person` and transport / routing in `CommunicationManager`.
