# Colorado Front Range dataset profiles

Each YAML file is a standalone, versioned build contract. Profiles do not
inherit mutable defaults, so a manifest can retain the exact profile file and
SHA-256 used for a build.

`supported` profiles describe the existing four-CBSA north-corridor workflow.
The six-MSA profile is `planned` until administrative OSM assignment and full
routing/capacity acceptance include Colorado Springs and Pueblo.

Generated person, household, place, schedule, and social-network data remains
local and must not be committed or published.
